Sonar vision for murky water

Underwater robots lose their cameras in murky water. This project trains a model to turn imaging sonar into vision-style features, so tag detection keeps working when the cameras cannot see.

Role
Independent research
When
December 2025 to present
Hardware
Jetson Orin Nano, imaging sonar data
Software
PyTorch, OpenCV, NumPy, ONNX, TensorRT FP16, ROS 2 (tf2, robot_localization)

The problem

Fiducial tags give an underwater robot fixed landmarks to localize against, but in turbid water the cameras see almost nothing while the sonar still returns a picture. This project learns a mapping from sonar returns to vision-style features, so an AcTag fiducial detector keeps working when murky water blinds the cameras.

How it works

  1. Preprocess. OpenCV and NumPy clean up each sonar frame and propose candidate tag regions.
  2. Translate. A transformer maps the sonar returns into vision-style features.
  3. Detect. The AcTag fiducial detector runs on those features.
  4. Localize. Detections feed a ROS 2 EKF (robot_localization with tf2) for pose estimation and loop closure.
  5. Deploy. The model runs in FP16 with TensorRT on a Jetson Orin Nano.

Where it stands

Running in FP16 on the Orin Nano, with detections feeding the EKF.
