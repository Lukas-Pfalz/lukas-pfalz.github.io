SLAM and path planning

A mobile robot that maps its surroundings, labels what it sees, and plans its own route through the map.

Role
Personal project
Hardware
Jetson Orin Nano, LiDAR, camera, IMU
Software
ROS 2, EKF sensor fusion, PyTorch to ONNX to TensorRT FP16, A* planner

How it works

  1. Sense. LiDAR, camera, and IMU publish into ROS 2.
  2. Fuse. An EKF fuses the sensors into a pose estimate.
  3. Label. A PyTorch perception model, exported to TensorRT FP16, labels what the camera sees.
  4. Map. Labeled observations build a semantic occupancy grid.
  5. Plan. A* searches the grid for a route to the goal.

Each stage runs as its own ROS 2 node, so any one of them can be swapped or tested alone.

Where it stands

Runs end to end on the robot, from raw sensors to a planned path.
